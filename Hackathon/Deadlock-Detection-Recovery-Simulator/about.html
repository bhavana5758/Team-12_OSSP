PROJECT OVERVIEW

About this simulator

A browser-based educational project for exploring deadlock detection and recovery in operating systems.

Project goal

Develop a system that detects deadlocks among processes and demonstrates suitable recovery strategies. The interface turns resource matrices and algorithm steps into an interactive learning workflow.

Learning outcomes

  • Understand resource allocation and circular wait.
  • Interpret allocation and request matrices.
  • Apply a detection algorithm to a given system state.
  • Compare recovery approaches and verify the updated state.

Technology stack

HTML5CSS3JavaScript

The project runs locally in a modern browser and does not require a backend or database.

Scope

All processes and resources are simulated. The project is intended for learning and demonstration, not for managing live operating-system resources.

Possible extensions

  • Animated graph updates driven by simulator state.
  • More resource types and pre-built test cases.
  • Step-by-step algorithm playback.
  • Exportable execution history and result reports.
