Resource allocation graph

A directed graph represents processes and resource types. Request edges point from a process to a resource; assignment edges point from a resource to a process.

Example: circular wait

Two processes each hold one resource and request the other.

Request edge: process → resourceAssignment edge: resource → process

What does a cycle mean?

With one instance of each resource type, a cycle in the resource-allocation graph is sufficient to indicate deadlock. With multiple instances, a cycle is necessary but not always sufficient.

How to read it

P1 requests R2, but R2 is assigned to P2. P2 requests R1, but R1 is assigned to P1. The circular dependency prevents either process from proceeding.
