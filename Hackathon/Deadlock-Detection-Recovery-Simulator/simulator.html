Ready to analyze

Load the example or enter a resource state, then select Run detection.

Model assumptions: the available vector is supplied by the user and must be consistent with the allocation data. The detector uses the classic Work/Finish method. A process with no allocation can be marked finished initially; remaining unfinished processes are reported as deadlocked candidates under the model.
