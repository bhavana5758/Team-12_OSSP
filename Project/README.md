## Project Overview

CampusHub is an Operating Systems project that provides separate Faculty and Student portals.

The Faculty Portal allows faculty members to manage assignments, while the Student Portal allows students to view assignments and submit their work.

The project uses a C-based backend running on Linux/Ubuntu.

## Objectives

- Provide separate Faculty and Student interfaces.
- Allow faculty to create and manage assignments.
- Allow students to view assignments.
- Allow students to submit assignments.
- Demonstrate file handling and file descriptors.
- Demonstrate Linux system calls.
- Implement a C-based backend server.
